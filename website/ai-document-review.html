How to check AI document review

Case Forge project · Published 13 September 2026 · Organisation guide

Use AI to suggest summaries and questions, then check every saved finding against the original document. Decide what material leaves your computer before you connect a cloud service.

Begin with one document and a small task

Ask for a short summary, a list of dates or a set of questions. Require a source quotation and page or section reference for each suggestion. An AI may omit context or produce an unsupported statement, so treat its output as a draft for review.

Summarise this document using only its contents. For each point, show the exact supporting quotation and where it appears. List anything uncertain separately. Do not infer a motive or decide who is right.

Check the source, not just the wording

Open the original and read the surrounding passage. Confirm who is speaking, whether the statement is quoted from someone else and whether a later sentence qualifies it. A quotation can be copied correctly while the conclusion drawn from it is still wrong.

In the current Case Forge local app preview, users can import PDF, text and Markdown files, request analysis and review suggested findings before choosing what to save. Screens on this website use fictional records. The public paid desktop app is still in development.

Understand local storage and cloud processing

A folder on your computer is local storage. Sending text from that folder to cloud AI is a separate action: the provider processes what you share. The local preview asks for consent before sending selected document text for cloud analysis and also supports a local model option. Review the provider’s settings and terms for your chosen connection.

The free toolkit does not include an AI subscription. An assistant needs local folder access to install or edit files for you; giving a link to an ordinary browser chat only provides instructions it can explain.

Watch for missing text

A scanned PDF may contain pictures of pages rather than selectable text. Check the extracted text before analysis. The current preview does not include OCR for image-only scans; use a suitable text extraction workflow and compare the result with the original.

Save findings deliberately

Keep the original document, your reviewed note and its source reference together. Reject unsupported suggestions. Add accepted dates to your case timeline and keep unanswered questions separate. Do not let an AI’s confidence substitute for checking.

AI review can help organise material. Obtain qualified advice for legal decisions; these instructions do not assess a case or predict an outcome.
