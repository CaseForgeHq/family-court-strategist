How to organise family court documents

Case Forge project · Published 13 September 2026 · Organisation guide

Keep an untouched copy of every original, give each record a clear reference and organise working copies in one case folder. A simple index makes it easier to find the source behind a note or question.

1. Start with originals and working copies

Create a case folder in a location you control. Keep original downloads, messages and scanned documents together, then use copies for highlighting and notes. Preserve the original filename and record where each file came from. Keep a separate backup you can restore.

The free Case Forge toolkit adds templates and AI guidance to your chosen folder. Its installer stops when an existing file would conflict; it does not silently replace it.

2. Give each record a stable reference

A reference such as DOC-001 stays useful even when a display name changes. In your index, record that reference, the original filename, a short description, the document date and where you obtained it. If a date is unknown, write “unknown” instead of guessing.

ReferenceWorking descriptionSourceQuestion to check
DOC-001Email about a proposed meetingOriginal email export, 8 September 2026Was the proposal accepted?
DOC-002Note made after the meetingPersonal note, 10 September 2026Does the calendar confirm the event date?

3. Keep notes separate from the source

Write summaries in a working note that links back to the original file and page or message date. Separate a direct quotation from your explanation of it. Record conflicting material alongside supporting material so your index remains useful when your understanding changes.

4. Build an index before analysing everything

Start with one document. Confirm its date, source and location, then add the next. Once you can reliably find your material, create a timeline with source references. Keep questions in a separate list for your next discussion.

Can AI do the filing?

An AI with access to your folder can help suggest names and summaries. Review proposed changes before accepting them. A browser chat cannot install the toolkit on your computer by itself. Read how to check AI document review before sharing sensitive records.

This is a filing workflow, not guidance on what a court requires. Check filing and evidence requirements with the relevant court or a qualified adviser.
