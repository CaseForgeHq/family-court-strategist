How to build a case timeline

Case Forge project · Published 13 September 2026 · Organisation guide

A useful case timeline puts events in date order and connects each entry to its source. Keep what a document says separate from what you infer, and make uncertainty visible.

Start with four fields

Use an event date, a short factual description, a source reference and a question or uncertainty. A spreadsheet, Markdown table or the Case Forge timeline template can hold this structure. Consistency matters more than the tool.

Fictional example: distinguish a proposal from an event
Event dateWhat the record saysSourceStill to check
8 September 2026An email proposed a meeting for 10 September.DOC-001, email dated 8 SeptemberWhether the recipient agreed.
10 September 2026A personal note records that a meeting took place.DOC-002, note dated 10 SeptemberWhether another record confirms the time.

Use the event date, and keep the document date

A letter written on Friday may describe an event from Monday. Put Monday in the event-date field and keep Friday in the source reference. If only the month is known, record the month and label the date as approximate. Do not convert an estimate into a precise date to make the table sort neatly.

Write one event per entry

Keep each description short enough to check against the original. “The email proposed a meeting” describes the record. “The meeting was agreed” adds a conclusion unless a response supports it. Link a response as another source or another entry.

Include gaps and competing accounts

If two records disagree, preserve both references and note the difference. Do not delete an entry simply because it complicates your account. A gap is a question to investigate, not proof of an explanation.

Review before sharing

  • Open each source and confirm the date and wording.
  • Check that filenames and page references still resolve.
  • Label estimates, disputed accounts and personal recollections.
  • Make a separate copy for sharing and check who should receive it.

If your records are scattered, start with the document organisation guide. If an AI drafts entries, follow the source-checking workflow before saving them.

A working chronology helps preparation. It does not establish facts or determine whether material is suitable for filing.
